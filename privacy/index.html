Analytics privacy

This portfolio works without analytics. Accepting or declining makes no difference to the content you can explore.

Optional Google Analytics

With your permission, this site uses Google Analytics 4 to understand visits, popular projects, navigation, downloads and contact actions. Google receives technical information such as device/browser details, approximate location and referral source. These reports help Sandra improve the portfolio.

The Google and Microsoft Clarity tags are blocked until you accept analytics. Declining sends no analytics data. Global Privacy Control is respected. Advertising storage, advertising user data, personalised advertising and Google signals are disabled.

Optional Microsoft Clarity

After you accept analytics, Microsoft Clarity records masked browsing sessions and measures clicks, scrolling, navigation and device information. This helps Sandra understand project engagement, dead clicks, page exits and usability on desktop and mobile. Session recordings represent page interactions, not a recording of your camera, microphone or screen outside this website.

Clarity uses the same analytics choice as Google Analytics, not a separate banner. Previous Google-only permission is refreshed before recording begins; previous declines remain declined. Neither service loads before acceptance. Advertising consent remains denied. No custom visitor identity, name, email address or telephone number is sent to Clarity.

Page content is explicitly masked for recordings, including dynamic project details and contact content. Input values remain masked. Public page paths and allowlisted project identifiers support analysis without custom personal identifiers. Because text masking does not redact all URLs, Clarity does not start on pages with unrecognised query parameters or fragments, or referrers containing query data. Known category filters, intro links and existing section anchors are permitted. Recording stops if navigation introduces an unsafe address or a contact link is used. Google Analytics continues with its existing fixed-label events.

When permitted, Clarity’s first-party _clck cookie supports a browser identifier and preferences, and _clsk links page views into a session. Device/browser data and approximate location may be processed. Microsoft explains its handling of data in the Microsoft Privacy Statement. Declining blocks the Clarity script entirely, including cookieless recording.

What is and isn’t measured

Portfolio events use fixed action labels, known page paths and project identifiers. Custom events never include email addresses, telephone numbers, form entries, search terms or link text. Page addresses exclude query strings and fragments. Referrals are limited to the referring origin. Campaign query parameters are intentionally excluded.

Google’s Enhanced Measurement handles PDF downloads and outbound links without duplicate custom events. It may include the public destination link and public PDF filename. It is not used to read or send contact message content. This site has no contact submission form.

Storage and changing your choice

Your analytics choice is stored locally for 180 days. If you accept, Google uses first-party analytics cookies, configured for up to 180 days, to measure visits and engagement. Use “Analytics privacy” in the footer on any page to change your choice. Withdrawing stops measurement, stops Clarity, clears this site’s Google Analytics and Clarity cookies, and reloads the page to unload both tracking scripts. It does not delete data previously received by Google.

Declined visits and visitors using blockers will not appear in analytics. Google handles data according to its partner sites information. Questions about this portfolio can be sent through the Contact page.
